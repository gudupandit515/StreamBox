# StreamBox

A YouTube-inspired personal media player for audio/video files you own or are licensed to use.

## Run it
1. Extract the ZIP.
2. Upload the folder to a static HTTPS host (for example, GitHub Pages or Netlify).
3. Open the site in Chrome on Android.
4. Add your media files using “Choose audio / video files”.

## Background playback
The player uses the browser's Media Session API. On supported Android browsers, audio may continue with the screen locked, but this is controlled by the browser/OS and is not guaranteed on every device. For best results, start playback first and do not force-close the browser.

This does not stream or modify YouTube content, remove YouTube ads, or bypass YouTube Premium. Use media you own or have permission to play.
